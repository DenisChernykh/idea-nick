# Idea Nick — frontend и API

Проект с отдельными frontend- и backend-приложениями на TypeScript.

## Возможности

- React-интерфейс на Vite.
- Отдельная серверная точка входа.
- Раздельная структура клиентского и серверного кода.

## Инженерные акценты

- Организация fullstack-проекта.
- Разделение ответственности frontend и API.
- Типизированная разработка на TypeScript.

## Стек

React, TypeScript, Vite.

## Навигация по коду

- [frontend/](frontend/) — публичный интерфейс.
- [backend/](backend/) — серверная часть.
