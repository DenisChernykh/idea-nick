# Ideanick — интерфейс идей и API

Проект с React-интерфейсом списка идей и отдельным Express API на TypeScript.

## Возможности

- Карточки идей с названием и описанием.
- Отдельный Express-сервер с маршрутом /ping.
- Раздельная структура frontend и backend.

## Инженерные акценты

- Организация fullstack-проекта и границ клиентского и серверного кода.
- Типизированные точки входа и компонентный интерфейс.

## Стек

React, TypeScript, Vite, Express.
